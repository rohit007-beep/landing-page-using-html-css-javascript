# CodePilot AI 🚀

A modern, fully responsive AI SaaS landing page built with pure **HTML**, **CSS**, and **JavaScript** — no frameworks, no dependencies.

---

## 📸 Preview

> A dark-themed, professional landing page for an AI automation platform targeting businesses, agencies, and startups.

---

## 📁 Project Structure

```
codepilot-ai/
├── index.html       # Main HTML file
├── style.css        # All styles and animations
├── script.js        # All JavaScript functionality
└── README.md        # Project documentation
```

---

## ✨ Features

- **Sticky Navbar** — Transparent blur navbar with smooth scroll to sections
- **Hero Section** — Animated heading, badge, and floating image
- **Trusted Logos** — Google, Microsoft, Amazon, Adobe
- **Feature Cards** — Image cards with hover zoom animation and scroll reveal
- **Stats Section** — Animated counters (500K+ Users, 50M+ Tasks, etc.)
- **How It Works** — 4-step process with gradient step numbers
- **Pricing Section** — 3-tier pricing with a highlighted "Most Popular" card
- **Testimonials** — 3 customer review cards with star ratings
- **FAQ Accordion** — Click to expand/collapse answers
- **Contact Section** — Quick links + contact form side by side
- **Responsive Footer** — Logo, nav links, and copyright

---

## ⚙️ JavaScript Functionality

| Feature | Description |
|---|---|
| FAQ Accordion | Opens/closes answers on click, only one open at a time |
| Scroll Reveal | Cards fade in smoothly when entering the viewport |
| Smooth Scroll | Nav links scroll to sections without page jump |
| Navbar Shadow | Border becomes visible when user scrolls down |
| Form Validation | Validates all fields + email format, shows success/error message |
| Active Nav Highlight | Nav link turns blue based on current visible section |

---

## 🎨 Tech Stack

- **HTML5** — Semantic structure
- **CSS3** — Custom properties (CSS variables), Flexbox, Grid, animations
- **JavaScript (ES6)** — DOM manipulation, IntersectionObserver, event listeners
- **Google Fonts** — Syne (headings) + DM Sans (body)
- **Unsplash** — Online images (no local assets needed)

## 🚀 Getting Started

1. Clone the repository
```bash
git clone https://github.com/your-username/codepilot-ai.git
```


3. Open `index.html` in your browser — that's it, no build step needed.

> **Tip:** Use the [Live Server](https://marketplace.visualstudio.com/items?itemName=ritwickdey.LiveServer) extension in VS Code for the best experience.
